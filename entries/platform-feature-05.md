## platform-feature-05

### Description

The Android platform provides accessibility services feature.

### Additional context

Accessibility services is a feature that allows applications to assist users with disabilities by reading screen content, performing user actions, and interacting with the device on the user’s behalf. 

### Demonstration

#### 01. Prepare the environment

Set up the required environment with:
* An emulated Google Pixel 6 running Android 12 (api level 31)

#### 02.

Navigate to “Settings” → “Accessibility” to view the apps listed under the “Downloaded apps” section that provide accessibility services

#### 03.

Select an app and toggle “Use app name” to activate its accessibility service

Because the Android platform provides accessibility services feature, your app is at risk of: 
- platform-feature-05-risk-01
- platform-feature-05-risk-02
- platform-feature-05-risk-03
